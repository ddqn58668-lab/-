# 高效复盘方法

标签：#工作 #复盘 #持续改进

好的复盘不是追究责任，而是把一次经历转译成下一次可以执行的选择。

## 三层提问

| 层次 | 关键问题               | 产出             |
| ---- | ---------------------- | ---------------- |
| 事实 | 实际发生了什么？       | 可验证的时间线   |
| 洞察 | 哪个假设被证实或推翻？ | 一条可迁移的经验 |
| 行动 | 下次具体改变什么？     | 一个明确的下一步 |

## 让复盘进入知识网络

把复盘中的方法论连接到 [[学习笔记/构建个人知识系统]]，它就不会随着项目结束而被遗忘。需要放慢节奏、重新校准时，也可以读读 [[生活随想/留白与灵感]]。

## 最小行动

每次复盘只保留一项最值得验证的改进，并为它指定负责人、完成日期和检查方式。小而持续的改变，比长篇总结更有价值。
